# مجلد الشهادات (Certificates)

شهادة الجذر القديمة `ARN_Technology_Root.cer` **أُلغيت** ولم تعد تُوزَّع أو تُثبَّت:

- ثُبِّتت سابقاً في مخزن ثقة Windows عبر المثبّت، وهذا مرفوض أمنياً.
- التوقيع الآن يعتمد على شهادة توقيع كود عامة (EV) تُدار خارج المستودع.
- كلمة مرور أي ملف `PFX` تُقرأ من متغير البيئة `ARN_PFX_PASSWORD` فقط.

لا تضع أي ملفات `.pfx` أو `.jks` أو مفاتيح خاصة داخل هذا المجلد — فهي مُستثناة في `.gitignore`.
