# خطة التطوير والإصلاح الشامل: البث الذكي، كافرات الألبومات، مشغل الموسيقى، ومشغل الفيديو الاحترافي

خطة متكاملة لإعادة بناء وبرمجة ميزة البث للشاشات والأجهزة الأخرى من الصفر، وضمان ظهور جميع كاڤرات الألبومات بدقة، وتصحيح سلوك مشغل الموسيقى المصغر لكي يختفي عند الإيقاف مع إمكانية إغلاقه يدوياً، وتزويد مشغل الفيديو بعناصر تحكم احترافية كاملة تشمل أزرار السابق والتالي والتحكم المتطور في الصوت.

---

## القرارات المؤكدة وخيارات المستخدم (User Decisions)

> [!IMPORTANT]
> تم تأكيد التفضيلات التالية بناءً على إجاباتك التفاعلية:
> - **آلية البث (Casting)**: إعادة برمجة البروتوكول الذكي مع كشف الأجهزة والشاشات على الشبكة والتحكم بها، مع توفير خيار البث عبر المشغلات الخارجية كبديل موثوق.
> - **مشغل الموسيقى المصغر (Mini Player)**: إخفاء المشغل تلقائياً عند انتهاء التشغيل أو الإيقاف التام، مع توفير زر إغلاق صريح (X) لإزالته فوراً من الشاشة دون تشويش.
> - **عناصر تحكم مشغل الفيديو (Video Player)**: إضافة أزرار السابق والقادم للتنقل بين الحلقات، مع إيماءات سحب عمودية للتحكم الفوري بالصوت والسطوع ومؤشر HUD عصري وزر لكتم/ضبط الصوت.

---

## 1. نظرة عامة والهدف الأساسي (Overview & Core Concept)

معالجة وحل 4 نقاط رئيسية لتحقيق تجربة استماع ومشاهدة سلسة واحترافية:
1. **إعادة بناء ميزة البث (Casting Engine Redesign)**:
   - محرك بحث متقدم يكتشف شاشات التلفاز الذكية والأجهزة على الشبكة المحلية (DLNA / UPnP / Smart TV / Web TV) بالتوازي مع خادم ARN.
   - إمكانية الإرسال والتحكم الكامل عن بُعد (تشغيل، إيقاف، تقديم، تأخير، تحكم بالصوت).
   - توفير مسار بديل عبر "مشاركة البث إلى تطبيق خارجي" (External Cast / Web Video Caster / VLC) لمنع أي فشل على الإطلاق.
2. **حل مشكلة عدم ظهور كاڤرات الألبومات (Album Covers Resolution)**:
   - فحص وتصحيح مسارات الصور القادمة من الـ API (بما في ذلك نهايات `/api/albums/{id}/cover` والتوافق مع التوكن).
   - توفير صور بديلة فنية متناسقة (Fallback to Artist Image / Distinctive Visual Art) بحيث لا تظهر أي بطاقة ألبوم فارغة أو بلون باهت.
3. **تحسين مشغل الموسيقى المصغر (Mini Player Lifecycle & Dismissal)**:
   - إضافة حالة إغلاق واضحة (`dismissed`) وإخفاء تلقائي عند الإيقاف التام.
   - تزويد الكبسولة بزر إغلاق أنيق (X) يتيح للمستخدم إخفاء الكبسولة في أي وقت لتفريغ مساحة الشاشة.
4. **مشغل فيديو متكامل واحترافي (Pro Video Player Experience)**:
   - أزرار السابق (`SkipPrevious`) والتالي (`SkipNext`) للتنقل السريع بين الحلقات والوسائط.
   - نظام إيماءات لمسي احترافي (سحب على يمين الشاشة للصوت، وسحب على يسار الشاشة لسطوع الشاشة).
   - منزلق وزر مخصص للصوت داخل شريط التحكم مع مؤشر رقمي فوري (HUD).

## 2. تجربة المستخدم والتصميم البصري (User Experience & Visual Design)

### تدفقات الاستخدام الرئيسية (Key User Flows)
1. **تدفق البث للشاشة الذكية**:
   - المستخدم يضغط على أيقونة البث (Cast) داخل مشغل الفيديو أو تفاصيل العمل أو الشاشة الرئيسية.
   - تظهر نافذة عصرية تعرض الشاشات المكتشفة مع رمز نوع الشاشة (تلفاز، متصفح، جهاز خارجي) وحالة الاتصال.
   - فور اختيار الجهاز، يتم إرسال رابط البث فورياً وتبدأ الشاشة بالعرض، مع فتح شاشة التحكم السريع أو التحكم بالبث مباشرة.
2. **تدفق كافرات الألبومات**:
   - عند فتح صفحة الفنان أو الألبومات، يتم تحميل الغلاف الأصلي بدقة فائقة عبر رابط موثوق.
   - في حال تعذر جلب الغلاف الأصلي، يتم الانتقال بسلاسة إلى غلاف المسار الأول أو صورة الفنان المعالج، مع مظهر زجاجي أنيق.
3. **تدفق مشغل الموسيقى المصغر**:
   - يظهر فقط أثناء وجود تراك قيد التشغيل أو في وضع الانتظار المؤقت.
   - يتضمن زر إغلاق (X) سريع ينهي ظهور الشريط فورياً إذا رغب المستخدم في تصفح هادئ.
   - يختفي تلقائياً عند انتهاء قائمة التشغيل.
4. **تدفق مشغل الفيديو الاحترافي**:
   - شريط تحكم وسطي وسفلي أنيق بلون أسود شفاف متدرج (Glassmorphic Dark Overlay).
   - أزرار مخصصة للحلقة السابقة والتالية.
   - سحب الإصبع عمودياً على الجانب الأيمن يُظهر شريط HUD صوتي فوري مع النسبة المئوية.
   - زر سريع للصوت يتيح كتم أو ضبط مستوى الصوت بدقة.

## 3. القرارات التقنية والهندسة المعمارية (Technical Architecture)

```
┌─────────────────────────────────────────────────────────────┐
│                       Media Services                        │
└──────────────────────────────┬──────────────────────────────┘
                               │
       ┌───────────────────────┼──────────────────────────────┐
       ▼                       ▼                              ▼
┌──────────────┐       ┌──────────────┐               ┌──────────────┐
│ Cast Engine  │       │ Audio Engine │               │ Video Engine │
│  (Rebuilt)   │       │(Mini Player) │               │ (Pro Player) │
└──────┬───────┘       └──────┬───────┘               └──────┬───────┘
       │                      │                              │
       ├─ Network Scan        ├─ Auto-Hide on Stop           ├─ Prev/Next
       ├─ Remote PlayTo       ├─ Explicit Close (X)          ├─ Swipe Volume HUD
       └─ External Player     └─ Safe Insets Sync            └─ Volume Slider
```

### 1. إعادة بناء محرك البث (Cast Architecture)
- **`CastManager` / `MediaRepository`**:
  - فحص أجهزة الشبكة وخادم ARN وتقديم قائمة متكاملة.
  - إرسال أوامر التشغيل عبر WebSocket/HTTP API للخادم والشاشات.
  - إضافة خيار إطلاق `Intent.ACTION_VIEW` إلى تطبيقات البث والتلفاز الخارجية المتثبتة على الجهاز لضمان التشغيل بنسبة 100%.

### 2. تصحيح كافرات الألبومات (Album Covers Pipeline)
- تحديث دالة `displayCover` في `Models.kt`:
  - إزالة الشروط التي قد تلغي الغلاف إذا كان يماثل صورة الفنان.
  - إضافة مسار الـ Fallback التلقائي `/api/albums/${id}/cover`.
  - معالجة الروابط في `ApiClient.getFullMediaUrl` لضمان إرفاق التوكن إن وُجد وتجنب الروابط المكسورة.

### 3. ضبط دورة حياة مشغل الموسيقى (Audio Player Controller)
- في `AudioPlayerController.kt`:
  - إضافة `isDismissed: StateFlow<Boolean>`.
  - دالة `dismissPlayer()` و `stopPlayback()`.
  - تحديث `MiniPlayerCapsule.kt` ليعتمد على `visible = currentTrack != null && !isDismissed && isPlaybackActive`.
  - إضافة أيقونة إغلاق (X) في أقصى اليسار/اليمين للمشغل.

### 4. عناصر تحكم مشغل الفيديو الاحترافي (Pro Video Player Controls)
- في `VideoPlayerScreen.kt`:
  - إضافة أزرار: `SkipPrevious` و `SkipNext`.
  - إضافة مستمع لإيماءات السحب العمودي `pointerInput` للتحكم في صوت النظام عبر `AudioManager` مع عرض مؤشر HUD عائم.
  - إضافة زر للتحكم بالصوت ومنزلق مدمج داخل شريط التحكم.
  - الحفاظ على المظهر السينمائي الراقي وتناسق الهوامش.

## خطة التنفيذ خطوة بخطوة (Step-by-Step Implementation)

1. **الخطوة الأولى**: تصحيح وتحسين منطق كافرات الألبومات في `Models.kt` و `ArtistDetailsScreen.kt` و `MediaRepository.kt`.
2. **الخطوة الثانية**: ترقية `AudioPlayerController.kt` و `MiniPlayerCapsule.kt` لدعم الإخفاء التلقائي عند التوقف وإضافة زر الإغلاق (X).
3. **الخطوة الثالثة**: إعادة بناء وبرمجة ميزة البث لشاشات وأجهزة أخرى من الصفر داخل `CastSelectionDialog.kt` و `MediaRepository.kt` وتوفير آلية البث الذكي والمشغلات الخارجية.
4. **الخطوة الرابعة**: تطوير `VideoPlayerScreen.kt` لتضمين أزرار السابق والقادم وإيماءات السحب لمستوى الصوت ومؤشر HUD ومنزلق الصوت.
5. **الخطوة الخامسة**: التحقق البرمجي وبناء التطبيق عبر `compile_applet` للتأكد من خلوه من أي أخطاء.
