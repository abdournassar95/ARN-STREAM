## 3. المعمارية: ما هو موجود فعلاً

```
                    ┌──────────────────────────────────────────────┐
   Browser  ───────▶│  Express (port 8096)                         │
   Android  ───────▶│  · optionalAuth → responseCache → licenseGate │
   Jellyfin ───────▶│  · 26 راوتراً + 57 مساراً داخل index.js       │
   DLNA TV  ───────▶│  · WebSocket: /ws/handoff /ws/syncplay /socket│
                    └───────┬───────────────┬──────────────┬────────┘
                            │               │              │
                    better-sqlite3     FFmpeg/ffprobe    DLNA/SSDP
                    (متزامن، WAL)      (subprocess)      (UDP + SOAP)
                            │
                    %APPDATA%/ARN_Stream/data/media.db
```

### نقاط قوة معمارية حقيقية (يجب الحفاظ عليها)

- **Direct Play أولاً**: `determineStreamStrategy` تختار Direct/Remux/Transcode، مع دعم `Range` (206) — أعلى كفاءة ممكنة.
- **WAL + busy_timeout + فهارس موجّهة** + `PRAGMA quick_check` مع `REINDEX` ذاتي عند التلف (فكرة عملية جداً).
- **دالة SQL مخصّصة `norm_ar`** لتطبيع العربية (همزات، تاء مربوطة، تشكيل، "ال") — ميزة إقليمية ممتازة.
- **تخزين مؤقت متعدد الطبقات**: React Query (5 دقائق) + Cache استجابات على الخادم + كاش صور Sharp + كاش بث IPTV.
- **تقليل حجم الحزم**: `lazyRetry` لكل صفحة + `manualChunks` يدوي لـ React/Query/Motion/Icons/i18n.
- **إغلاق رشيق (Graceful shutdown)**: قتل FFmpeg، إيقاف SSDP، إغلاق DB، ومهلة 3 ثوانٍ قسرية.
- **طبقة توافق Jellyfin** كاملة (Router + DTO + Query + Stream + Socket) — استثمار كبير ونادر.

### 5.2 تفصيل أعلى خمس مخاطر

#### 🔴 SEC-01 — تسريب أسرار وقاعدة بيانات حقيقية في المستودع

القاعدة المرفوعة ليست قالباً فارغاً:

```text
settings:  jwt_secret = c2de67ea...54e6645989ae2c6f9f...      ← يُستخدم لتوقيع كل الرموز
users:     1 | ABOOOOD | admin | $2b$10$esdIw...
           2 | 0000    | user  | $2b$10$SLJGf...
movies:    E:\افلام\EUC.mp4 ...
```

**الأثر:** من يملك المستودع يستطيع: (أ) توقيع JWT بدور `admin` والوصول لأي تثبيت يستخدم هذا السر، (ب) كسر كلمات المرور دون اتصال، (ج) معرفة بنية الملفات الشخصية للمطوّر. كما أن 46 MB تُبطئ كل `clone`.

**الإصلاح الفوري:**
```bash
git rm --cached server/data/media.db data/media.db
git commit -m "chore(security): untrack production database"
# ثم: git filter-repo --path server/data/media.db --invert-paths  (مع force-push)
# وإبطال السر: setSetting('jwt_secret', crypto.randomBytes(32).toString('hex'))
# وإجبار كل المستخدمين على إعادة الدخول + تغيير كلمات المرور
```

#### 🔴 SEC-02 — مفتاح توقيع التطبيق وكلمة مروره

```yaml
keytool -genkeypair ... -storepass arn_stream_2026 -keypass arn_stream_2026
git add app/arn_technology_release.jks && git push
```

**الأثر:** أي طرف يمكنه إصدار نسخة محدّثة "شرعية" من التطبيق تُثبَّت فوق نسخة المستخدم (تحديث خبيث). هذا أسوأ سيناريو لسلسلة التوريد في تطبيقات أندرويد.
**الإصلاح:** توليد مفتاح جديد، تخزينه في GitHub Secrets (`KEYSTORE_BASE64`, `STORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`)، فك التشفير داخل الـ job فقط، وحذف السجل من التاريخ.

#### 🔴 SEC-03 — زرع شهادة جذر

```
[Run]
Filename: "certutil.exe"; Parameters: "-addstore -f ""Root"" ...ARN_Technology_Root.cer"
Filename: "certutil.exe"; Parameters: "-addstore -f ""TrustedPublisher"" ..."
```

الشهادة المفحوصة: `CN=ARN Technology, O=ARN Technology, C=EG` — **ذاتية التوقيع**، صالحة حتى 2036، RSA 3072.
**الأثر:** تثبيت جذر غير مدقَّق على `LocalMachine` يجعل أي شهادة يصدرها هذا الجذر موثوقة من النظام (HTTPS, code signing) → مخاطرة MITM جماعية إن تسرّب المفتاح الخاص، وسلوك يُصنّف غالباً كـ PUA من مضادات الفيروسات. كما أن "تخطي SmartScreen" لا يُحلّ بشهادة جذر، بل بشهادة EV code signing من CA عامة.
**الإصلاح:** إزالة قسم `[Run]` بالكامل، وشراء شهادة توقيع كود حقيقية (أو التوزيع بدون توقيع مع تحذير واضح). يجب أيضاً أن يتضمّن المثبّت خطوة إزالة الشهادة عند إلغاء التثبيت إن كانت مثبتة سابقاً.

#### 🔴 SEC-04 — دورة حياة الرمز (Token)

- يُخزَّن في `localStorage` → أي XSS يسرق جلسة 30 يوماً.
- يُكرَّر في كوكي `httpOnly:false` → لا حماية من XSS.
- يُمرَّر في الرابط `?token=` لتيارات الفيديو والتحميل → يظهر في سجل المتصفح، وخادم الوكيل، و**سجل الخادم نفسه**:
  ```js
  app.use((req, res, next) => { console.log(`[API] ${req.method} ${req.url}`); ... });
  ```
- لا يوجد `jti` / `token_version`، ولا قائمة إبطال، فلا يمكن تسجيل الخروج من الأجهزة الأخرى.

**الإصلاح المقترح:**
1. كوكي `httpOnly; Secure; SameSite=Lax` فقط + إزالة التوكن من `localStorage`.
2. لمسارات الميديا: استخدام كوكي الجلسة بدل `?token=`، أو توقيع روابط قصيرة العمر (HMAC + `exp`) مخصصة للملف.
3. إضافة `token_version` في جدول المستخدمين وتضمينه في الـ payload؛ تغيير كلمة المرور/الصلاحيات يزيد الرقم فتُبطل كل الرموز.
4. تقصير الصلاحية إلى 15 دقيقة + Refresh Token.

#### 🟠 SEC-06/07 — التحكّم عن بُعد والجلسات

```js
router.use(optionalAuth);                    // handoff.js — لا requireAuth
router.post('/register', ...)                // أي زائر يسجّل جهازاً باسم أي مستخدم
router.get('/devices', ...)                  // قائمة كل الأجهزة على الشبكة
```

```js
// index.js — لا تحقق من الهوية عند ترقية الاتصال
const deviceId = url.searchParams.get('deviceId');
sessionManager.attachWebSocket(deviceId, ws, {...});   // يستبدل wsClient للجهاز نفسه
```

**الأثر:** مهاجم على نفس الشبكة (Wi‑Fi منزلي/مقهى) يمكنه: حجب جهاز الضحية عن أوامر التحكم باستبدال مقبسه، انتحال جهاز لعرض حالة تشغيل مزيفة، والظهور في قائمة الأجهزة. في SyncPlay، `userId` و`username` يأتيان من الـ query مباشرة فتُنتحل هوية أي مشارك.
**الإصلاح:** ربط كل جهاز بـ `userId` ومفتاح جهاز سري (`device_secret`) يُنشأ مرة واحدة؛ تمرير التوكن في `Sec-WebSocket-Protocol` أو رسالة مصادقة أولى؛ رفض أي `deviceId` مسجّل لمستخدم آخر.

## 16. خلاصة الحكم

ARN Stream **منتج مثير للإعجاب من حيث الطموح والاتساع**: 90 ألف سطر، 300 مسار، عميل Jellyfin، تطبيق أندرويد، وطبقة ذكاء عربية للبحث. لكنه يعاني **فجوة كلاسيكية بين سرعة إضافة الميزات ونضج الهندسة**: أسرار في المستودع، واجهات تحكم بلا مصادقة، صفر اختبارات، وملفات بحجم 4,600 سطر.

الخبر الجيد: **كل المشاكل الحرجة قابلة للإصلاح في أقل من أسبوع**، والبنية الأساسية (SQLite WAL، Direct Play، lazy loading، الفهارس، التوثيق) سليمة بما يكفي للبناء عليها. تنفيذ المرحلتين 0 و1 وحدهما يرفع تقييم الأمان من **3.0 إلى 7.5+** ويحوّل المشروع من "مشروع شخصي واسع" إلى **منصة قابلة للتوزيع بأمان**.
