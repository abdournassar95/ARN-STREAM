هذا المستند يوثّق **كل ما تم إصلاحه** رداً على التحليل الشامل (`docs/COMPREHENSIVE_ANALYSIS_AR.md`)، مع ما تبقّى.

## 1. الأسرار والمستودع

| قبل | بعد |
| :--- | :--- |
| `server/data/media.db` (46 MB) مرفوع ويحتوي `jwt_secret` وهاشات كلمات مرور | أُخرج من التتبع + `.gitignore` يمنع `*.db` و`server/data/` |

## 2. المصادقة والجلسات

- **الكوكي**: `httpOnly` + `SameSite=Lax` + `Secure` تلقائياً خلف HTTPS (`authCookieOptions`).
- **إلغاء الجلسات**: عمود `token_version` يُضمَّن في الرمز ويُقارَن عند كل طلب؛ يتغير تلقائياً عند تغيير كلمة المرور/الدور/التفعيل/المكتبات المسموحة.
- **تدوير الأسرار المسرّبة**: أي `jwt_secret` مطابق للقيمة المنشورة يُدوَّر عند أول تشغيل.
- **إزالة `?token=`** من كل مسارات الـ API العامة؛ بقي مقبولاً فقط لمسارات الوسائط (توافق مشغلات Android/ExoPlayer القديمة).
- **إخفاء التوكنات من السجلات**: التسجيل يعتمد `req.path` فقط دون query string.
- **سياسة كلمات المرور**: 8 أحرف على الأقل + رفض الشائعة، مطبقة في الإنشاء والتعديل وتغيير كلمة المرور.
- **مقارنة ثابتة الزمن** للمفتاح الداخلي (`timingSafeEqual`) وإزالة الاعتماد على `Host` القابل للتزوير.

## 3. واجهات كانت مكشوفة

| المسار | قبل | بعد |
| :--- | :--- | :--- |
| `POST /api/handoff/register` | بلا مصادقة (وأخذ `userId` من الجسم) | `requireAuth` + الملكية من التوكن |
| `GET /api/handoff/devices` | يسرد كل الأجهزة | مصادقة + تصفية حسب المالك |
| `POST /api/handoff/state`, `GET /state/:deviceId` | مفتوحة | مصادقة + تحقق ملكية |
| `WS /ws/handoff` | أي اتصال بـ `deviceId` يُقبل | مصادقة (كوكي/توكن) + منع اختطاف جهاز مستخدم آخر |
| `WS /ws/syncplay` | `userId` من الـ query | الهوية من التوكن؛ الضيوف بمعرّف عشوائي غير قابل للانتحال |
| `GET /api/scan/status` | عام | مصادقة |
| `POST /api/scan` | تجاوز عبر "لا يوجد Origin" | مفتاح داخلي (loopback فقط) أو أدمن |
| `GET /api/auth/*` | كوكي غير httpOnly | كوكي محمي |

## 4. الشبكة والترويسات

- **CORS**: من `*` إلى قائمة: نفس المضيف + loopback + `CORS_ORIGINS`، مع `credentials`.
- **تحديد المعدل**: عام (600/دقيقة) + دخول (50/15 دقيقة) + إعداد (10/ساعة) + وكيل IPTV (1200/دقيقة)، مع ترويسات `RateLimit-*`.
- **ترويسات الأمان**: `nosniff`, `SAMEORIGIN`, `Referrer-Policy`, `COOP`, `CORP`, `Permissions-Policy`, و**CSP** في الإنتاج، وHSTS خلف HTTPS فقط.
- **حدود الجسم**: JSON 2MB وurlencoded 1MB بدلاً من 10MB عالمياً.

## 6. البناء والتوزيع

- CI جديد (`.github/workflows/ci.yml`): اختبارات + فحص أمني + بناء الواجهة على كل فرع، وبناء APK، وإصدار فقط عند الوسم `v*`.
- حذف `build-android.yml` القديم الذي كان يحتوي كلمة مرور المفتاح ويكتب في المستودع.
- المثبّت لم يعد يثبّت شهادة جذر، ويحذفها عند إلغاء التثبيت.
- أندرويد: `allowBackup=false`، توقيع اختياري آمن، `versionCode=2`، `versionName=3.1.0`.
- توحيد الإصدارات على **3.1.0** في الجذر والخادم والواجهة والمثبّت وأندرويد.

## 7. الموثوقية والجودة

- **24 اختبار وحدة** (`node:test`) تعمل بدون أي اعتمادية أصلية: تطبيع العربية، سياسة كلمات المرور، محدِّد المعدل، CORS/الترويسات.
- استخراج دوال نقية إلى `server/utils/` لتكون قابلة للاختبار.
- إصلاح ترويسة `Range`: تقييد `end`، فهم `bytes=-N`، رفض القيم غير الصالحة بـ 416، ودعم `HEAD`.
- `predev.js` لم يعد يقتل أي عملية تستخدم المنفذ — فقط عمليات Node/ARN.

## 8. ما تبقّى (متعمَّد أو مؤجّل)

1. **تاريخ Git**: الملفات أُخرجت من التتبع، لكن نسخها القديمة ما زالت في `.git`. إن كان المستودع عاماً فيجب `git filter-repo` + إعادة كتابة التاريخ + تدوير كل الأسرار (تم فعلياً على مستوى الكود).
2. **`archiver`**: 3 تنبيهات متوسطة؛ الإصلاح المتاح يعني تخفيض الإصدار إلى 7 وقد يكسر واجهة `ZipArchive`. يحتاج اختباراً يدوياً قبل التنفيذ.
3. **FTS5 والبحث**: ما زال `LIKE`؛ يحتاج ترحيلاً مُختبَراً على قاعدة بيانات حقيقية.
4. **تفكيك `Player.jsx` (4,597 سطراً)**: تحسين هيكلي كبير لم يُنفَّذ في هذه الجولة.
5. **i18n**: 9,108 نص عربي ما زال مضمّناً؛ يحتاج ترحيلاً تدريجياً إلى ملفات الترجمة.
6. **محتوى Jellyfin (GPL)**: أُضيف إشعار ترخيص؛ ينبغي مراجعة قانونية قبل التوزيع التجاري.
7. **شهادة توقيع كود حقيقية** لتفادي SmartScreen بدلاً من الشهادة الذاتية.
8. **`/api/image/:id/full|thumb` بلا مصادقة (مقصود مؤقتاً)**: تطبيق أندرويد يحمّل الملصقات عبر
   Coil بمُحمِّل صور مستقل لا يرسل الكوكي ولا `Authorization`، وتقييد المسار الآن يكسر كل
   الملصقات هناك. الحل الصحيح (لم يُنفَّذ لتفادي كسر التوافق دون اختبار جهاز حقيقي):
   إضافة `ImageLoader` إلى Coil يستخدم `ApiClient.okHttpClient` ثم تفعيل `requireAuth`،
   أو توليد روابط موقّعة قصيرة العمر (`?sig=&exp=`).
   المخاطر الحالية: تعداد بسيط لأسماء الملصقات فقط، بدون أي بيانات مستخدم.
9. **كلمة مرور `PFX`**: أصبحت من `ARN_PFX_PASSWORD` فقط؛ يجب التأكد من عدم وجود نسخ قديمة
   في سجلات CI أو في ملفات `.ps1` سابقة (تم فحص المستودع).
