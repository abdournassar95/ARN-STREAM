## 🔐 1. نظام المصادقة والأمان (Authentication & Security)

### 1.1 الترويسات القياسية (HTTP Headers)
* **المصادقة:** `Authorization: Bearer <JWT_TOKEN>`
* **المحتوى:** `Content-Type: application/json`
* **المفتاح الداخلي لمشغل النظام:** `x-arn-internal-key: <INTERNAL_KEY>` (يُستخدم للتواصل المحلي الصامت بين مشغل سطح المكتب والخادم بدون طلب تسجيل دخول).

## 🎬 3. مسارات المكتبات ومحتوى الوسائط (Libraries & Media)

### 3.1 إدارة وتصفح المكتبات (`/api/libraries`)
* `GET /api/libraries`: جلب جميع المكتبات المسجلة في النظام مع عدد العناصر في كل مكتبة.
* `POST /api/libraries`: إضافة مكتبة وسائط جديدة (تحديد المسار والنوع: `movies`، `series`، `music`، `quran`).
* `DELETE /api/libraries/:id`: حذف مكتبة ومساراتها من قاعدة البيانات.

### 3.2 الأفلام والمسلسلات (`/api/movies` & `/api/series`)
* `GET /api/movies`: جلب قائمة الأفلام مع دعم الفلترة حسب المكتبة، التصنيف، والترتيب.
* `GET /api/movies/:id`: جلب التفاصيل الكاملة لفيلم محدد (الميتاداتا، الجودة، مسار الترجمة، والبوستر).
* `GET /api/series`: جلب قائمة المسلسلات المتاحة.
* `GET /api/series/:id`: جلب بيانات المسلسل والمواسم التابعة له.
* `GET /api/series/:id/episodes`: جلب حلقات موسم محدد.

### 3.3 الصوتيات والموسيقى والقرآن (`/api`)
* `GET /api/artists`: جلب قائمة الفنانين والقراء مع عدد ألبوماتهم وتراكاتهم.
* `GET /api/artists/:id`: جلب ملف الفنان وقائمة ألبوماته وتراكاته الأكثر استماعاً.
* `GET /api/albums`: جلب جميع الألبومات الموسيقية أو المصاحف المرتلة.
* `GET /api/albums/:id`: تفاصيل الألبوم وقائمة مساراته الصوتية.
* `GET /api/tracks`: استعراض كافة التراكات الصوتية مع مدتها وصيغتها.

## 🔍 4. محرك البحث التنبؤي الذكي (`/api/search`)

* **المسار:** `GET /api/search`
* **المعاملات (Query Params):**
  - `q`: نص البحث (يدعم اللغة العربية مع معالجة التشكيل، الهمزات، وأل التعريف تلقائياً).
  - `type`: نوع البحث (`all`، `movie`، `series`، `track`، `artist`).
  - `limit`: الحد الأقصى لعدد النتائج (الافتراضي: 20).
* **الاستجابة:**
```json
{
  "data": [
    {
      "id": 12,
      "title": "Inception",
      "year": 2010,
      "type": "movie",
      "libraryName": "أفلام أجنبية",
      "poster": "/api/image/45/thumb",
      "rank": 1
    }
  ],
  "prediction": "Inception"
}
```

## 📺 5. بث الوسائط والترجمات (Streaming & Playback)

### 5.1 البث المباشر مع استئناف التحميل (Range Streaming)
* `GET /api/stream/video/:id`: بث ملف الفيديو بجودته الأصلية مع دعم كامل لترويسة `Range: bytes=start-end` لتقديم وتأخير الفيديو فورياً.
* `GET /api/stream/audio/:id`: بث المسارات الصوتية (MP3, FLAC, AAC, WAV) بدقة فائقة.
* `GET /api/subtitles/:id`: جلب ملف الترجمة المرفق (SRT, VTT) تلقائياً بصيغة WebVTT المتوافقة مع المتصفحات.

### 5.2 القنوات التلفزيونية الحية (`/api/live`)
* `GET /api/live/channels`: قائمة القنوات التلفزيونية المتاحة (بي إن سبورت، الكأس، ناشيونال جيوغرافيك، وغيرها) مع روابط البث وشعارات القنوات.

### 5.3 حفظ نقطة التوقف واستئناف المشاهدة (`/api/playback`)
* `GET /api/playback/progress/:mediaType/:mediaId`: جلب موضع آخر ثانية توقف عندها المستخدم.
* `POST /api/playback/progress`: حفظ تقدم المشاهدة/الاستماع دورياً في قاعدة البيانات.

## 📲 6. التحكم عن بُعد ونقل الجلسات (PlayTo & Handoff)

* `GET /api/handoff/sessions`: رصد كافة الأجهزة النشطة المرتبطة بالحساب حالياً.
* `POST /api/handoff/transfer`: نقل البث الحالي فورياً إلى جهاز آخر مع الاحتفاظ بنفس الثانية بالضبط.
* `POST /api/handoff/command`: إرسال أوامر التحكم الفورية للجهاز المستهدف (`play`, `pause`, `seek`, `volume`, `mute`).

---

## 🍿 7. حفلات المشاهدة الجماعية (Watch Party)

* `POST /api/watch-party/rooms`: إنشاء غرفة مشاهدة جماعية جديدة برمز دخول فريد.
* `GET /api/watch-party/rooms/:roomId`: جلب بيانات الغرفة والوسائط المعروضة وقائمة المشاهدين.
* `POST /api/watch-party/rooms/:roomId/join`: الانضمام إلى غرفة المشاهدة.

---

## 🖼️ 8. الصور والكاش الذكي (Images & Caching)

* `GET /api/image/:id/full`: جلب البوستر أو الخلفية بدقتها الكاملة (مع تحويل وكاش WebP تلقائي).
* `GET /api/image/:id/thumb`: جلب صورة مصغرة سريعة التحميل لواجهات العرض والبحث.
* `GET /api/avatars/:filename`: استعراض الصور الشخصية المرفوعة للمستخدمين.

---

## 🛠️ 9. الصيانة وفحص الوسائط (Scanner & Admin)

* `POST /api/scan`: بدء فحص ومزامنة مجلدات الوسائط (يدعم الفحص اللحظي أو عبر الخلفية `?async=true`).
* `POST /api/database/backup`: أخذ نسخة احتياطية فورية من قاعدة البيانات إلى مجلد `backups/`.
* `GET /api/dashboard/stats`: إحصائيات النظام الشاملة (عدد المستخدمين، حجم الوسائط، استهلاك الذاكرة).

---

## ⚡ 10. بروتوكول الاتصال اللحظي (WebSockets)

* **الرابط:** `ws://<server-ip>:8096`
* **الرسائل المدعومة:**
  - `HELLO`: تسجيل تعريف الجهاز والمتصفح ونظام التشغيل.
  - `PLAYBACK_STATE`: تحديث حالة المشغل (تشغيل/إيقاف/الموضع الحالي).
  - `PLAYTO_COMMAND`: تلقي أمر تحكم عن بُعد من هاتف أو حاسوب آخر.
  - `PARTY_SYNC`: مزامنة توقيت العرض بين أعضاء غرفة المشاهدة الجماعية.
  - `PARTY_CHAT`: إرسال واستقبال رسائل المحادثة النصية داخل الحفلة.
